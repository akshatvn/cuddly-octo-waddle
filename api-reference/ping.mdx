## Overview

The `/ping` endpoint is a simple health check endpoint that returns a JSON response. It's useful for:

- Verifying the API is running
- Monitoring uptime
- Load balancer health checks
- Quick connectivity tests

## Endpoint

```
GET /ping
```

## Request

This endpoint requires no parameters, headers, or authentication.

<ParamField query="none" type="none">
  No parameters required
</ParamField>

## Response

<ResponseField name="data" type="string" required>
  Always returns the string "pong"
</ResponseField>

### Response Example

<ResponseExample>

```json Success Response
{
  "data": "pong"
}
```

</ResponseExample>

</Note>

<Warning>
  On Render's free tier, the API may spin down after 15 minutes of inactivity. The first request after inactivity may take 30-60 seconds to respond while the server starts up.
</Warning>
