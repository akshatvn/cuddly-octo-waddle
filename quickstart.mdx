## Try the Live API

The easiest way to get started is to try the live API right now:

<CodeGroup>

```bash cURL
curl https://cuddly-octo-waddle-rmrq.onrender.com/ping
```

```javascript JavaScript
fetch('https://cuddly-octo-waddle-rmrq.onrender.com/ping')
  .then(response => response.json())
  .then(data => console.log(data));
```

```python Python
import requests

response = requests.get('https://cuddly-octo-waddle-rmrq.onrender.com/ping')
print(response.json())
```

</CodeGroup>

**Expected Response:**
```json
{
  "data": "pong"
}
```

## Run Locally

Want to run the API on your own machine? Follow these steps:

<Steps>
  <Step title="Clone the Repository">
    ```bash
    git clone https://github.com/akshatvn/cuddly-octo-waddle.git
    cd cuddly-octo-waddle
    ```
  </Step>

  <Step title="Install Dependencies">
    Make sure you have Python 3.7+ installed, then:
    ```bash
    pip install -r requirements.txt
    ```
  </Step>

  <Step title="Run the Server">
    ```bash
    python main.py
    ```

    Or using uvicorn directly:
    ```bash
    uvicorn main:app --reload
    ```
  </Step>

  <Step title="Test the Endpoint">
    Open your browser or use curl:
    ```bash
    curl http://localhost:8000/ping
    ```
  </Step>
</Steps>
